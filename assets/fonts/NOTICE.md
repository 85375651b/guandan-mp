## Droid Sans Fallback

Copyright (c) 2005–2008, The Android Open Source Project.

The unmodified `DroidSansFallbackFull.ttf` is bundled from the Fedora
`google-droid-sans-fonts` package (upstream: Android Open Source Project).
It supplies Chinese glyphs in every UI font family, including player names and
monospace fields. See [LICENSE-DroidSansFallback.txt](LICENSE-DroidSansFallback.txt)
for the original copyright notice and Apache License, Version 2.0.

Both fonts are embedded in the executable; installing a system font is unnecessary.
